# Market Game — сайт для палат, банков и спонсоров

Англоязычный сайт **marketgame.biz**: программа бизнес-игр для торговых
палат США и международных бизнес-сообществ, которую оплачивает сама палата
или спонсор (банк). Главная цель сайта — заявка на бесплатную демо-игру.

Саму игру сайт не описывает — это делает [marketgame.club](https://marketgame.club/en/).
Все продуктовые решения записаны в [CONCEPT.md](CONCEPT.md).

## Как устроен сайт

Страницы собирает генератор [Eleventy](https://www.11ty.dev/) из шаблонов
и таблиц данных. Главное следствие: **страниц штатов 51, а шаблон один** —
`src/state.njk`. Поправили его — поменялись все штаты сразу. Руками страницы
штатов никто не пишет.

Сборка идёт на GitHub сама, при каждом изменении (см. «Публикация»).
Ставить что-либо на компьютер не нужно: всё правится через веб-интерфейс
GitHub — карандаш на нужном файле → Commit changes.

```
src/
  index.njk               главная: «кто вы / где», карта штатов, пакеты, калькулятор…
  state.njk               шаблон страницы штата — из него 51 страница
  nationwide.njk          компании из нескольких штатов
  international.njk       международные бизнес-сообщества
  banks.njk               для банков и спонсоров
  privacy.njk             политика конфиденциальности
  print/                  три PDF-документа (см. «PDF»)

  _includes/partials/     общие блоки страниц — тексты правятся здесь:
    programs.njk            пакеты, форматы, опции
    calculator.njk          калькулятор окупаемости
    banks.njk               блок «For banks & sponsors» (стоит на всех страницах)
    benefits.njk            что получает палата
    faq.njk                 вопросы и ответы
    how.njk, cta.njk, about.njk, experience.njk, map.njk, selector.njk,
    chambers.njk, open-games.njk, scopes.njk, stats.njk

  _data/                  ТАБЛИЦЫ ДАННЫХ — цифры правятся здесь:
    pricing.json            все цены, опции, форматы и билеты
    states.json             51 штат: пояс, клетка на карте, правило открытой игры, статистика
    schedule.json           формат и длительность открытых игр, отмены
    site.json               адрес приёма заявок, контакты, реквизиты компании
    chambers.json           палаты и их статусы — пишется автоматически из таблицы продаж
    banks.json              банки-партнёры по штатам — тоже автоматически

  assets/js/              скрипты: core (общее), selector (первый экран и карта),
                          schedule (открытые игры), calc (калькулятор),
                          lists (поиск палат, выбор штатов банком), forms (заявка),
                          print (PDF)
  assets/css/             site.css — вся вёрстка; print.css — PDF-документы

apps-script/Code.gs       приёмник заявок для Google Apps Script
scripts/sync-sheet.mjs    выгрузка палат и банков из таблицы продаж
.github/workflows/        сборка и публикация
```

## Что где менять

| Что меняете | Где |
|---|---|
| Любая цена, опция, цена билета | `src/_data/pricing.json` — одно место на весь сайт, калькулятор и PDF |
| Тексты блоков | нужный файл в `src/_includes/partials/` |
| Тексты страницы штата | `src/state.njk` и блоки, которые он подключает |
| Адрес приёма заявок | `src/_data/site.json` → `formEndpoint` |
| Email, WhatsApp | `src/_data/site.json` → `contact` |
| Реквизиты компании | `src/_data/site.json` → `company` (см. ниже) |
| День и время открытой игры штата | `src/_data/states.json` → поле `game` у штата |
| Отменить открытую игру | `src/_data/schedule.json` → `exceptions` |
| Цвета, отступы, шрифты | `src/assets/css/site.css` |

Цены хранятся **только** в `pricing.json`: карточки, таблицы, калькулятор,
PDF и `llms.txt` берут их оттуда. Поменяли цифру — она поменялась везде.

## Реквизиты компании

Пока американской компании нет, реквизиты на сайте не показываются.
Когда появятся — заполните в `src/_data/site.json`:

```json
"company": {
  "legalName": "Market Game LLC",
  "address": "…",
  "registration": "…"
}
```

Они появятся в подвале и в политике конфиденциальности. Заодно заведите
почту на домене (например, hello@marketgame.biz) и впишите её в
`contact.email` — американский B2B пишет на email, а не в мессенджеры.
Пока email пустой, запасным контактом в форме служит WhatsApp.

До продвижения раздела International в Европе реквизиты обязательны:
этого требует GDPR.

## Открытые игры в штатах

Одна открытая онлайн-игра в месяц в каждом штате, по местному времени.
Расписание не хранится списком, а считается от сегодняшней даты по
правилу штата в `states.json`:

```json
"game": { "nth": 1, "weekday": 2, "time": "19:00" }
```

`nth` — неделя месяца (1–4), `weekday` — день недели (0 — воскресенье,
2 — вторник), `time` — местное время штата. Сейчас штаты разложены
по 12 слотам (4 недели × вторник, среда, четверг), по 4–5 штатов из разных
поясов в каждом. Если нагрузка велика, штаты одного пояса можно ставить
в один слот и проводить одной игрой.

Отмена — строка в `schedule.json` → `exceptions`:
`"2026-12-24"` — в этот день ничего; `"2026-12-24 TX"` — только Техас.

Кнопка «Join» ведёт на marketgame.club с метками `utm_campaign=TX` и
`utm_content=2026-10-06`: форма заявки на .club их сохраняет, менеджер
увидит штат и дату.

## База палат: из таблицы продаж на сайт

Источник правды — ваша Google-таблица продаж. На сайт попадают только
открытые поля, через два отдельных листа.

**1. Лист «Сайт — палаты».** Колонки (можно по-русски):

| Штат | Палата | Город | Сайт | Статус | Дата договора | Публиковать | Спонсор | Публиковать спонсора |
|---|---|---|---|---|---|---|---|---|
| TX | Greater Austin Chamber | Austin | austinchamber.com | Подписан | 2026-10-02 | Да | First Community Bank | Да |

- **Штат** — двухбуквенный код (TX, OH, DC).
- **Статус** «Подписан» — палата работает; любое другое значение — свободна.
- **Founding Chamber** штата определяется сам: самая ранняя дата договора.
- **Публиковать** «Да» — палата согласилась на упоминание статуса. Без
  согласия палата остаётся в списке, но без статуса. Пункт о согласии
  нужно внести в договор.

Удобнее всего собрать этот лист формулами (`QUERY` или `FILTER`) из
основного листа продаж — тогда контакты и цены туда физически не попадают.

**2. Лист «Сайт — банки»:** Штат · Банк · Территория (Штат или Метро) ·
Метро · Эксклюзив (Да/Нет) · Активен (Да/Нет) · Публиковать (Да/Нет).

**3. Опубликуйте оба листа:** Файл → Поделиться → Опубликовать в интернете →
выбрать лист → формат CSV → Опубликовать. Скопируйте обе ссылки.

**4. Секреты в GitHub:** Settings → Secrets and variables → Actions →
New repository secret: `CHAMBERS_CSV_URL` и `BANKS_CSV_URL`.

Дальше GitHub раз в час забирает листы, обновляет `chambers.json` и
`banks.json` (история статусов видна в коммитах) и пересобирает сайт.
Если в таблице ничего не поменялось, сайт не трогается. Запустить
вручную: Actions → Build and deploy → Run workflow.

**Полный список палат** (в США их больше 7 000) пока нужно собрать —
он же станет базой для обзвона.

## Статистика штатов и индексация

У каждого штата в `states.json` есть поле `stats`. Пока оно `null`,
блок цифр не показывается. Формат:

```json
"stats": {
  "smallBusinesses": 3300000,
  "employmentShare": 45.1,
  "applications": 520000,
  "applicationsYear": 2025,
  "survival5": 49.5,
  "sbaLoans": 5200,
  "sbaYear": "FY2025",
  "sources": "SBA Office of Advocacy, U.S. Census Bureau (BFS), BLS (BED), SBA"
}
```

Цифры выше — пример формата, а не данные. Источники: SBA Office of
Advocacy (Small Business Profiles), Census Bureau (Business Formation
Statistics), BLS (Business Employment Dynamics), SBA (данные по кредитам).

**Пока у штата нет ни статистики, ни списка палат, его страница закрыта
от индексации** (`noindex`) и не входит в `sitemap.xml`: 51 почти одинаковая
страница выглядела бы для Google как дорвеи. Появились данные — страница
открывается сама, при следующей сборке.

## Заявки

Форма — одна на три случая (палата, банк, спонсор), с разными полями.
Заявка уходит в Google Apps Script, который пишет строку в таблицу продаж
(свой лист для каждого типа) и присылает уведомление в Telegram — так же,
как на marketgame.club.

**Настройка, минут пятнадцать:**

1. Откройте таблицу продаж → Расширения → Apps Script.
2. Вставьте содержимое `apps-script/Code.gs` вместо всего кода.
3. Настройки проекта → Свойства скрипта: `BOT_TOKEN` и `CHAT_ID`. Можно
   взять того же бота и ту же группу, что у marketgame.club.
4. Выберите функцию `checkSetup` → Выполнить. Она проверит ключи, пришлёт
   тестовое сообщение и создаст листы «Заявки — палаты / банки / спонсоры».
5. Развернуть → Новое развёртывание → Веб-приложение, «Запуск от имени: я»,
   «Доступ: все» → скопировать адрес `…/exec`.
6. Впишите адрес в `src/_data/site.json` → `formEndpoint`.

Пока адрес пустой, форма честно пишет, что она не подключена, и
предлагает связаться напрямую.

После любой правки `Code.gs`: Развернуть → Управление развёртываниями →
карандаш → Версия: новая → Развернуть. Адрес при этом не меняется.

## PDF

Три документа, которые сохраняются из браузера как PDF:

| Адрес | Для кого |
|---|---|
| `/print/brief/` | Program brief — палата отправляет правлению |
| `/print/prospectus/` | Sponsor prospectus — палата отправляет банку, со своим названием |
| `/print/bank/` | Bank partner brief — для банков |

Сверху — поля (палата, спонсор, штат, контакт): они подставляются в
документ сразу и сохраняются в адресе страницы, так что заполненный
документ можно переслать ссылкой. Кнопка «Save as PDF» открывает окно
печати, где выбирается «Сохранить как PDF». Формат — US Letter.

## Публикация

Сайт публикуется на GitHub Pages через GitHub Actions
(`.github/workflows/deploy.yml`) при каждом изменении ветки `main`.

1. **Репозиторий сейчас приватный.** GitHub Pages для приватных
   репозиториев работает только на платных тарифах (GitHub Pro — несколько
   долларов в месяц). Второй вариант — сделать репозиторий публичным, как у
   marketgame.club: секретов в коде нет, токены живут в настройках.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Там же, Custom domain: `marketgame.biz` → Save.
4. У регистратора домена — записи DNS:

   | Тип | Имя | Значение |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | ph001player1-lab.github.io |

5. Когда DNS разойдётся (от 15 минут до суток), поставьте галочку
   **Enforce HTTPS**.

GitHub отключает расписание в репозиториях без активности 60 дней —
тогда раз в час обновление остановится. Включается обратно кнопкой в
Actions.
